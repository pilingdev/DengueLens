### Phase 0 — Cold Start & Service Initialization (`main.dart`)

The process entry point is `main()` in `lib/main.dart`. This is a **synchronous-blocking** initialization sequence — the app does not render any UI until all `await` calls resolve.

---

#### Step 0.1 — Flutter Engine Bootstrap
```dart
WidgetsFlutterBinding.ensureInitialized();
```
**What happens:** Binds the Flutter widget engine to the native platform channel before any async platform calls can be made. Without this, any `await` on platform plugins before `runApp()` would throw. No UI is rendered yet.

**State change:** Platform channels become available.

---

#### Step 0.2 — Firebase Platform Initialization
```dart
await Firebase.initializeApp(
  options: DefaultFirebaseOptions.currentPlatform,
);
```
**What happens:** Reads `firebase_options.dart` (generated by FlutterFire CLI) and initializes the Firebase SDK with platform-specific API keys, project IDs, and app IDs. Establishes the Firebase app instance used by all subsequent Firebase services.

**Error handling:** If Firebase fails to initialize (e.g., corrupted `google-services.json`), an unhandled exception crashes the app at startup. No graceful recovery — this is treated as a fatal configuration error.

---

#### Step 0.3 — Anonymous Authentication
```dart
try {
  await FirebaseAuth.instance.signInAnonymously();
} catch (e) {
  debugPrint("Failed to sign in anonymously: $e");
}
```
**What happens:** Creates (or retrieves a cached) anonymous Firebase user. This UID is required by Firestore security rules to permit `sightings` collection writes. The token is cached by the Firebase SDK and auto-refreshed.

**Error handling:** Wrapped in `try/catch`. If sign-in fails (no internet at cold start, Firebase outage), the error is silently logged via `debugPrint`. The app continues — offline-first write queue handles the case where auth is unavailable during upload.

**State change:** `FirebaseAuth.instance.currentUser` becomes non-null.

---

#### Step 0.4 — TFLite Model Loading (`TfliteService.init()`)
```dart
await TfliteService().init();
```
**Singleton check:** `if (_initialized) return;` — idempotent, safe to call multiple times.

**Internal execution:**
```
1. rootBundle.load('Model/yolov8n_detector.tflite')
   → Loads raw bytes from Flutter asset bundle into memory
   → Interpreter.fromBuffer(bytes) → _detectorInterpreter

2. rootBundle.load('Model/mobilenetv3_mosquito_classifier.tflite')
   → Interpreter.fromBuffer(bytes) → _classifierInterpreter

3. rootBundle.loadString('Model/labels_detector.txt')
   → split on [\r\n]+ → filter empty → _detectorLabels: List<String>

4. rootBundle.loadString('Model/labels_classifier.txt')
   → split on [\r\n]+ → filter empty → _classifierLabels: List<String>
   → ["Aegypti", "Albopictus", "Anopheles", "Culex", "Non-Mosquito"]

5. _detectorInterpreter.getOutputTensors().first.shape
   → if shape[1] > shape[2]: _outputAnchorMajor = true
   → _numAnchors = anchor dimension count (typically 8400 for YOLOv8n)
   → _numChannels = channel dimension count
   → _initialized = true
```
**Error handling:** If `rootBundle.load` fails (asset not bundled), a `FlutterError` is thrown — fatal at startup. Models are required assets; no fallback exists.

**Performance note:** Both interpreter allocations occur here, not at inference time. This makes the first `predict()` call fast.

### Phase 5 — Two-Stage On-Device AI Inference (`TfliteService.predict()`)

> This is the computational core of Dengue Lens. All inference runs entirely on-device — no network call is made.

#### Step 5.1 — Image I/O and EXIF Correction
```dart
final bytes = await imageFile.readAsBytes();
img.Image? original = img.decodeImage(bytes);
if (original == null) {
  throw Exception('Could not decode image: ${imageFile.path}');
}
original = img.bakeOrientation(original);
```
**`img.bakeOrientation()`** reads the EXIF orientation tag and rotates/flips pixel data so `width`/`height` reflect the visual presentation. Without this, portrait-shot images would be processed sideways, causing detection failures.

---

#### Step 5.2 — Stage 1 Input: Letterbox Preprocessing (YOLOv8 standard)
```dart
static const int _inputSize = 640;

// 1. Compute scale ratio to fit longest edge to 640px
final double ratio = targetSize / math.max(original.width, original.height);
final int newUnpadW = (original.width * ratio).round();
final int newUnpadH = (original.height * ratio).round();

// 2. Resize preserving aspect ratio
final resized = img.copyResize(
  original,
  width: newUnpadW,
  height: newUnpadH,
  interpolation: img.Interpolation.linear,
);

// 3. Create 640×640 gray canvas (YOLO standard padding: 114, 114, 114)
final padded = img.Image(width: targetSize, height: targetSize);
img.fill(padded, color: img.ColorRgb8(114, 114, 114));

// 4. Compute centering offsets
final int dx = ((targetSize - newUnpadW) / 2).round();
final int dy = ((targetSize - newUnpadH) / 2).round();

// 5. Paste resized image centered on gray canvas
img.compositeImage(padded, resized, dstX: dx, dstY: dy);
```
**Why letterbox?** YOLOv8 requires exactly 640×640 input. Letterboxing preserves aspect ratio (no squishing distortion) and pads with neutral gray — the same gray value used during model training.

#### Step 5.3 — Tensor Construction (`imageToInputTensor`)
```dart
// lib/utils/image_utils.dart
List<List<List<List<double>>>> imageToInputTensor(img.Image image) {
  return List.generate(1, (_) =>              // batch dim = 1
    List.generate(image.height, (y) =>        // height = 640
      List.generate(image.width, (x) {        // width = 640
        final pixel = image.getPixel(x, y);
        return [
          pixel.r / 255.0,                    // normalize to [0, 1]
          pixel.g / 255.0,
          pixel.b / 255.0,
        ];
      }),
    ),
  );
}
// Output shape: [1][640][640][3]  dtype: float32
```

#### Step 5.5 — Output Shape Adaptation
```dart
// At init() time, shape was detected:
// _outputAnchorMajor = (outShape[1] > outShape[2])
// _numAnchors = anchor count (typically 8400 for 640px input)
// _numChannels = 4 coords + num_classes (= 5 for single-class "Mosquito")

double _readOutput(List<dynamic> output, int channel, int anchor) {
  return _outputAnchorMajor
      ? (output[0][anchor][channel] as num).toDouble()  // [batch][anchor][channel]
      : (output[0][channel][anchor] as num).toDouble(); // [batch][channel][anchor]
}
```

#### Step 5.6 — YOLO Version Detection & Confidence Parsing
```dart
// YOLOv5 has explicit objectness score at channel 4 (numChannels = 6 or 10)
// YOLOv8 does not (classOffset = 4 directly)
final bool hasObjectness = numChannels == 6 || numChannels == 10;
final int classOffset = hasObjectness ? 5 : 4;

double _ensureProbability(double value) {
  // TFLite exports may output raw logits instead of 0-1 probabilities
  return (value < 0.0 || value > 1.0) ? _sigmoid(value) : value;
}
double _sigmoid(double x) => 1.0 / (1.0 + math.exp(-x));
```

#### Step 5.7 — Anchor Parsing Loop (8400 iterations)
```dart
const double confidenceThreshold = 0.20;

for (var anchor = 0; anchor < numAnchors; anchor++) {
  final double objectness = hasObjectness
      ? _ensureProbability(_readOutput(output, 4, anchor))
      : 1.0;

  double maxClassScore = -1.0;
  for (var cls = 0; cls < yoloClasses; cls++) {
    final double classScore = _ensureProbability(
      _readOutput(output, classOffset + cls, anchor),
    );
    final double combinedScore = objectness * classScore;
    if (combinedScore > maxClassScore) maxClassScore = combinedScore;
  }

  if (maxClassScore > confidenceThreshold) {
    // Decode center-format box and un-letterbox back to original image coords
    double cx = _toInputPixels(_readOutput(output, 0, anchor), targetSize);
    double cy = _toInputPixels(_readOutput(output, 1, anchor), targetSize);
    double w  = _toInputPixels(_readOutput(output, 2, anchor), targetSize);
    double h  = _toInputPixels(_readOutput(output, 3, anchor), targetSize);

    // Remove letterbox padding to get original image coordinates
    double origCx = (cx - dx) / ratio;
    double origCy = (cy - dy) / ratio;
    double origW  = w / ratio;
    double origH  = h / ratio;

    double left = (origCx - origW / 2).clamp(0.0, imgW);
    double top  = (origCy - origH / 2).clamp(0.0, imgH);
    double right   = (left + origW).clamp(0.0, imgW);
    double bottom  = (top  + origH).clamp(0.0, imgH);

    rawDetections.add(Detection(
      label: 'Mosquito',
      confidence: maxClassScore,
      boundingBox: Rect.fromLTRB(left, top, right, bottom),
    ));
  }
}
```

#### Step 5.8 — Non-Maximum Suppression (NMS)
```dart
rawDetections.sort((a, b) => b.confidence.compareTo(a.confidence));

for (final det in rawDetections) {
  bool keep = true;
  for (final nmsDet in nmsDetections) {
    final intersect = det.boundingBox.intersect(nmsDet.boundingBox);
    if (intersect.width > 0 && intersect.height > 0) {
      final interArea = intersect.width * intersect.height;
      final unionArea = (det.boundingBox.width * det.boundingBox.height)
                      + (nmsDet.boundingBox.width * nmsDet.boundingBox.height)
                      - interArea;
      final iou = interArea / unionArea;
      if (iou > 0.45) { keep = false; break; }  // IoU threshold: 0.45
    }
  }
  if (keep) nmsDetections.add(det);
}
```
**NMS purpose:** Multiple anchors often fire on the same object. NMS keeps the highest-confidence box and suppresses overlapping boxes with IoU > 0.45.

#### Step 5.10 — Stage 2: MobileNetV3 Crop & Classify (per detection)
```dart
for (var i = 0; i < cappedDetections.length; i++) {
  if (finalSpeciesDetections.length >= _maxDetections) break; // hard stop

  // A. Crop bounding box from original HIGH-RESOLUTION image
  final crop = img.copyCrop(original, x: x, y: y, width: w, height: h);

  // B. Resize to 224×224 (MobileNetV3 input size)
  final resizedCrop = img.copyResize(
    crop, width: 224, height: 224, interpolation: img.Interpolation.linear,
  );

  // C. Build classifier input tensor — RAW pixels [0,255], NO normalization
  //    The model's built-in Rescaling(1/127.5, offset=-1) layer handles it
  final classifierInput = imageToClassifierInputTensor(resizedCrop);
  // shape: [1][224][224][3]  values: [0.0, 255.0]

  // D. Run MobileNetV3-Small
  final List<List<double>> classifierOutput = List.generate(
    1, (_) => List.filled(_classifierLabels.length, 0.0),
  );
  _classifierInterpreter.run(classifierInput, classifierOutput);
  // output: [1][5] softmax probabilities

  // E. Argmax → species label
  int bestClsIdx = 0;
  double maxProb = -1.0;
  for (int c = 0; c < probs.length; c++) {
    if (probs[c] > maxProb) { maxProb = probs[c]; bestClsIdx = c; }
  }
  final String speciesLabel = _classifierLabels[bestClsIdx];

  // F. False-positive filter: discard if classified as Non-Mosquito
  if (speciesLabel.toLowerCase() == 'non-mosquito') continue;

  finalSpeciesDetections.add(Detection(
    label: speciesLabel,       // Aegypti | Albopictus | Anopheles | Culex
    confidence: maxProb,       // classifier probability (0.0–1.0)
    boundingBox: det.boundingBox,
  ));
}

return PredictionResult(
  detections: finalSpeciesDetections,
  imageSize: Size(original.width.toDouble(), original.height.toDouble()),
);
```

### Phase 7 — Connectivity Check (`ConnectivityService.hasInternetAccess()`)

```dart
Future<bool> hasInternetAccess() async {
  // Layer 1: Check OS network interface (fast, no network round-trip)
  final List<ConnectivityResult> results = await Connectivity().checkConnectivity();
  if (results.contains(ConnectivityResult.none)) {
    return false;  // No interface (airplane mode, WiFi off, mobile off)
  }

  // Layer 2: Verify actual internet routing (DNS + HTTP, 5s timeout)
  try {
    final response = await http.head(
      Uri.parse('https://tile.openstreetmap.org'),
    ).timeout(const Duration(seconds: 5));
    return response.statusCode < 500;
    // statusCode < 500 means the server responded (even 404 = internet is up)
  } catch (_) {
    // Timeout, DNS resolution failure, or TLS error
    return false;  // Interface is up but routing is broken (captive portal, ISP issue)
  }
}
```
**Why two-layer check?** A device can have WiFi connected but no internet (e.g., captive portal). The HTTP HEAD to OpenStreetMap confirms end-to-end routing without downloading any data.

```dart
Future<Position?> getCurrentPosition() async {
  // 1. Check if GPS hardware/service is enabled
  bool serviceEnabled = await Geolocator.isLocationServiceEnabled();
  if (!serviceEnabled) return null;  // GPS turned off in device settings

  // 2. Check app permission
  LocationPermission permission = await Geolocator.checkPermission();

  // 3. Request permission if not yet granted
  if (permission == LocationPermission.denied) {
    permission = await Geolocator.requestPermission();
    if (permission == LocationPermission.denied) return null;  // User denied
  }

  // 4. Handle permanently denied (user checked "Never ask again")
  if (permission == LocationPermission.deniedForever) return null;

  // 5. Acquire position with platform-specific settings
  try {
    LocationSettings locationSettings;
    if (defaultTargetPlatform == TargetPlatform.android) {
      locationSettings = AndroidSettings(
        accuracy: LocationAccuracy.high,
        timeLimit: Duration(seconds: 10),
        forceLocationManager: true,  // bypass Google Play Services for compatibility
      );
    } else {
      locationSettings = LocationSettings(
        accuracy: LocationAccuracy.high,
        timeLimit: Duration(seconds: 10),
      );
    }
    return await Geolocator.getCurrentPosition(locationSettings: locationSettings);
  } catch (e) {
    return null;  // Timeout or hardware error
  }
}
```

**`UploadQueueService._drainQueue()`:**
```dart
Future<void> _drainQueue() async {
  if (_isDraining || _queueBox.isEmpty) return;
  _isDraining = true;

  try {
    // 1. Collect items due for retry (up to 10)
    final now = DateTime.now();
    final itemsToProcess = <String, Map<dynamic, dynamic>>{};
    for (var key in _queueBox.keys) {
      final item = _queueBox.get(key) as Map<dynamic, dynamic>;
      final nextRetryTime = DateTime.parse(item['nextRetryTime'] as String);
      if (now.isAfter(nextRetryTime) || now.isAtSameMomentAs(nextRetryTime)) {
        itemsToProcess[key as String] = item;
        if (itemsToProcess.length >= 10) break;
      }
    }
    if (itemsToProcess.isEmpty) return;

    // 2. Connectivity check (avoids wasting Firestore quota on known-offline)
    final hasInternet = await ConnectivityService().hasInternetAccess();
    if (!hasInternet) return;

    // 3. Ensure Firebase Auth session
    User? user = FirebaseAuth.instance.currentUser;
    if (user == null) {
      final authResult = await FirebaseAuth.instance.signInAnonymously();
      user = authResult.user;
    }

    // 4. Build and commit Firestore WriteBatch (atomic multi-doc write)
    final db = FirebaseFirestore.instance;
    final batch = db.batch();
    for (var entry in itemsToProcess.entries) {
      final item = entry.value;
      final docRef = db.collection('sightings').doc();  // auto-generated ID
      batch.set(docRef, {
        'species':    item['species'],
        'lat':        item['lat'],
        'lng':        item['lng'],
        'confidence': item['confidence'],
        'timestamp':  Timestamp.fromDate(DateTime.parse(item['timestamp'] as String)),
        'userId':     user?.uid ?? 'unknown',
      });
    }

    try {
      await batch.commit();
      // 5a. Success: remove from queue
      for (var key in itemsToProcess.keys) {
        await _queueBox.delete(key);
      }

    } on FirebaseException catch (e) {
      await _handleDrainError(itemsToProcess, e);
    } catch (e) {
      await _handleDrainError(itemsToProcess, Exception(e.toString()));
    }

  } finally {
    _isDraining = false;
  }
}
```

**`_handleDrainError()` — Retry Strategy:**
```dart
Future<void> _handleDrainError(items, error) async {
  bool isPermanent = false;
  if (error is FirebaseException) {
    // Permanent errors — retrying won't help
    if (['permission-denied', 'invalid-argument', 'unauthenticated'].contains(error.code)) {
      isPermanent = true;
    }
    // Transient: 'resource-exhausted' (quota), 'unavailable' (503) → retry
  }

  for (var entry in items.entries) {
    if (isPermanent) {
      // Dead letter: move item out of main queue, preserve for debugging
      await _deadLetterBox.put(entry.key, entry.value);
      await _queueBox.delete(entry.key);
    } else {
      // Exponential backoff: 2s → 4s → 8s → 16s → ... → 60s (capped)
      int retryCount = (item['retryCount'] as int? ?? 0) + 1;
      int backoffSeconds = math.min(1 << retryCount, 60);
      item['retryCount'] = retryCount;
      item['nextRetryTime'] = DateTime.now()
          .add(Duration(seconds: backoffSeconds)).toIso8601String();
      await _queueBox.put(entry.key, item);
    }
  }
}
```

## Part 3 — Error & Edge Case Matrix

| Scenario | Where It Occurs | Method Response | UX Outcome |
|----------|----------------|-----------------|------------|
| Firebase init fails | `main()` Step 0.2 | Unhandled exception | Fatal crash |
| Anonymous auth fails (no net) | `main()` Step 0.3 | `debugPrint` + continue | App loads; upload fails gracefully later |
| TFLite asset missing | `TfliteService.init()` | `FlutterError` thrown | Fatal crash |
| User cancels camera | `ImagePicker.pickImage()` | `photo == null` → return | Silent no-op, home resumes |
| Camera permission denied | `picker.pickImage()` | Returns null or throws | No image picked; no snackbar (OS handles prompt) |
| Unsupported file extension | Gallery validate | `showSnackBar` | User informed, no processing |
| Image not decodable | `img.decodeImage()` | Returns null → `Exception` | Loading overlay dismissed, snackbar: "Prediction failed" |
| All detections are Non-Mosquito | Classifier loop | `continue` past all | `finalSpeciesDetections` empty → "No Mosquito Detected" dialog |
| No internet at Share time | `_shareResult()` | `_showNoInternetDialog()` | AlertDialog; user can still Record locally |
| GPS disabled | `Geolocator.isLocationServiceEnabled()` | Returns `null` Position | Record saved without coords; Share shows snackbar |
| GPS permission denied forever | `Geolocator.checkPermission()` | Returns `null` Position | Same as GPS disabled |
| GPS timeout (10s) | `Geolocator.getCurrentPosition()` | `catch` → `null` | Same as GPS disabled |
| Firestore write fails (transient) | `batch.commit()` | Exponential backoff in queue | Retried in 2s, 4s, 8s…60s automatically |
| Firestore write fails (permanent) | `_handleDrainError()` | Move to dead-letter Hive box | Silently removed from retry queue |
| Queue drain already running | `_drainQueue()` guard | `_isDraining == true` → return | Prevents concurrent writes |
| Duplicate sighting in 1 minute | `enqueue()` dedup check | `_queueBox.containsKey(key)` → return | Sighting not double-uploaded |
| History exceeds 12 records | `HistoryService.addRecord()` | Delete oldest from Hive + disk | Auto-managed, user unaware |
| Map opened offline | `PointMapScreen._initMapData()` | `_isOffline = true` | Offline banner shown; map tiles unavailable |
| Map GPS unavailable | `_fetchUserLocation()` | Fallback to Kuala Lumpur coords | Snackbar + map centers on KL |
| Tutorial replay | FAB → `_showReplayConfirmation()` | `resetTutorial()` → `_showTutorial=true` | Full 5-step overlay re-shown |
